How this works

“How similar are these languages?” has more than one answer, so each is measured separately and none is folded into a single score.

Family tree is the position of both languages in Glottolog’s classification: 0 means the same language, 1 means no known common ancestor. It measures structure, not time; some families are subdivided far more finely than others.

Core words compares 40 basic words (I, two, water, eye…) using LDND, a sound-based edit distance corrected for chance resemblance. Around 1.0 is what unrelated languages score, so the shaded band on the scale shows the range of 98% of unrelated pairs.

Distance is between the places each language comes from, not everywhere it is spoken today, so English is placed in England and Spanish in Spain.
